Overview

Give AI full understanding of your Java, Kotlin & Python codebase.

You open an AI chat to get help with your project, and before you can even ask the question you spend ten minutes pasting files and explaining your class structure. Then the AI suggests a class that doesn’t exist.

Getting started

pip

pip install jctx

# download the latest release zip, unzip it, then:
Setup.bat   # run as administrator

How to use it

  1. Installpip install jctx
  2. RunJctx "path/to/project" — context.txt appears in the project folder.
  3. PastePaste it into any AI chat, then ask your question.

Commands

CommandWhat it does
Jctx <project_folder>Write context.txt into the project and print the dashboard
--mdWrite a Markdown context.md instead
--slimOnly class names and method signatures
--no-treeSkip the file tree section
--clipboardCopy the report to the clipboard
--printAlso print the report to the console

FAQ & troubleshooting

Does it upload my code?

No. It runs locally and only writes a file.

What does it skip?

build/, target/, .git/, node_modules/, .gradle/, .idea/ and compiled files — plus anything in .jctxignore.
