Overview

An advanced text editor beyond Notepad — and the app that grew into Notes+.

Notepad hasn’t really changed in thirty years. Notes started as my Notepad clone and kept going: themes per file and for everything at once, image backgrounds, fonts, automatic backups — and its own encryption, so a text file can be locked.

Getting started

Requirements: Windows 10 or 11 and Java 21+ (the JRE Installer sets it up in one click).

  1. Install Java onceDownload the JRE Installer, unzip it and click Start Installing JRE — no admin rights. (Skip this if you already have Java 21 or newer.)
  2. Download the appGrab the zip from the Download page.
  3. Unzip anywhere writableDesktop or Documents — the app saves its settings in its own folder.
  4. Run the .exeWindows SmartScreen may warn on first run because the exe isn’t code-signed: More info → Run anyway.

How to use it

  1. WriteIt works like Notepad: type, open and save plain .txt files.
  2. Theme one fileDesign → Change Current File Background / Text Color gives just this file its own colours.
  3. Theme everythingDesign → Change Universal Background / Text Color restyles every file at once.
  4. Use a pictureDesign → Set Image As Background puts an image behind your text.
  5. Lock a filePrivacy → Enable Encryption saves the file scrambled; Decrypt Current File turns it back.
  6. Back upPrivacy → Enable Backup and Backup Directory keep copies in a folder you choose.
  7. Write JavaThe Dev menu compiles and runs the Java file you have open.

Notes

The encryption in Notes is a cipher I wrote myself: every character is transformed with a random seed. It keeps casual eyes off a file — it is obfuscation, not cryptographic security, so don’t use it for anything that truly matters. (Notes+, its successor, uses AES-256-GCM.)

FAQ & troubleshooting

Is the encryption secure?

It’s a home-made, seeded character cipher — good against a casual glance, not against a determined attacker.

Where are my settings?

In saves.txt next to the exe.

“needs Java 21 or newer”

Install Java once with the JRE Installer (github.com/Shashwat-Gupta57/JRE-Installer), or point JAVA_HOME at a Java 21+ install.

Windows SmartScreen blocked it.

The exe isn’t code-signed. Click More info → Run anyway. The source is public on GitHub if you’d rather build it yourself.

My settings or scores don’t save.

The app writes next to its exe. Unzip it somewhere you can write to, not inside Program Files.

Where does it look for Java?

%LOCALAPPDATA%\OpenJDK Adoptium JRE - SG\JRE first (where the JRE Installer puts it), then %JAVA_HOME%.
