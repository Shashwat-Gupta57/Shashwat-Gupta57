Overview

Pick any colour, copy it as RGB, HEX or HSB.

A tiny tool I built twice: first in Swing, then again from scratch in JavaFX. Pick a colour and the whole window becomes it, with its RGB, HEX and HSB codes one click away from the clipboard — the thing I kept needing while designing my other apps.

Getting started

Requirements: Windows 10 or 11 and Java 21+ (the JRE Installer sets it up in one click).

  1. Install Java onceDownload the JRE Installer, unzip it and click Start Installing JRE — no admin rights. (Skip this if you already have Java 21 or newer.)
  2. Download the appGrab the zip from the Download page.
  3. Unzip anywhere writableDesktop or Documents — the app saves its settings in its own folder.
  4. Run the .exeWindows SmartScreen may warn on first run because the exe isn’t code-signed: More info → Run anyway.

How to use it

  1. PickClick Change Colour and choose any colour.
  2. CopyEach of RGB, HEX and HSB has its own Copy button.
  3. PasteThe code is on your clipboard, ready for CSS, design tools or code.

FAQ & troubleshooting

“needs Java 21 or newer”

Install Java once with the JRE Installer (github.com/Shashwat-Gupta57/JRE-Installer), or point JAVA_HOME at a Java 21+ install.

Windows SmartScreen blocked it.

The exe isn’t code-signed. Click More info → Run anyway. The source is public on GitHub if you’d rather build it yourself.

My settings or scores don’t save.

The app writes next to its exe. Unzip it somewhere you can write to, not inside Program Files.

Where does it look for Java?

%LOCALAPPDATA%\OpenJDK Adoptium JRE - SG\JRE first (where the JRE Installer puts it), then %JAVA_HOME%.
