The story

Why NGlobe

Wireshark and Fiddler are incredibly powerful, but they show your traffic as endless rows of text. They have no sense of place. When your laptop quietly talks to a server on another continent, you never feel it.

NGlobe makes it visible. It intercepts your machine’s traffic, looks up where every request is going, and flies it across an interactive 3D globe in real time — so tracking requests routed to faraway data centres stop being invisible.

02

Highlights

What it does.

01

Interactive 3D globe

Built on Deck.gl and MapLibre for smooth 60 fps rendering.

02

Packets as particles

Every request becomes a particle flying to its destination server.

03

HTTPS too

mitmproxy captures both HTTP and decrypted HTTPS traffic.

04

Rich analytics

Exact IPs, autonomous systems, hostnames and transfer volumes in a live sidebar.

05

Zero configuration

nglobe start — a wizard handles certificates, proxy settings and GeoIP databases.

06

History

Every event is written asynchronously to SQLite, so you can look back.

03

Install

Get it running.

git clone https://github.com/Shashwat-Gupta57/NGlobe
cd NGlobe && pip install .
nglobe start

Under the hood

How it’s built.

Capture

Pipeline
Python 3.11 · FastAPI event pipeline
Geo

Transport
WebSocket batches to the browser
Frontend
React · TypeScript · Tailwind · Zustand
Visuals
Deck.gl · MapLibre GL · Framer Motion
Storage
SQLite via SQLModel
