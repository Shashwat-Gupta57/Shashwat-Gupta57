Overview

The Google Drive library that lets Talken keep your files in your own storage.

Talken sends four-gigabyte videos without owning a single file server. The trick is that your files never leave your own Google Drive — and this library is how. It is a standalone module that handles sign-in, folders, uploads, downloads, sharing and quotas on the user’s own Drive.

Notes

Tokens are plain strings the app stores itself, so the library never decides where secrets live. Every call that can fail throws a DriveException with a reason — wrap calls in DriveRetry.run to retry only what waiting can fix.
