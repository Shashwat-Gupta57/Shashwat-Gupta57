01

The story

Why Drive Handler

Talken sends four-gigabyte videos without owning a single file server. The trick is that your files never leave your own Google Drive — and this library is how. It is a standalone module that handles sign-in, folders, uploads, downloads, sharing and quotas on the user’s own Drive.

Its best idea is about failure. "Your Drive is full" and "you are going too fast" are both HTTP 403 — so a naive client either hammers Google forever or gives up on a temporary hiccup. Drive Handler classifies every failure into a reason, knows which ones are worth retrying and which need the user, and has a sentence ready that a person can actually read.

There are two siblings: DriveHandler for the JavaFX desktop app, and DriveAndroid — a deliberate standalone copy for Android with PKCE sign-in and resumable, cancellable streaming transfers.

Everything it does

Every feature.

01

OAuth, every way

Desktop consent flow, cancel detection, an embedded web view, and "Continue with Google" identity claims.

02

Folders by path

ensureFolderPath creates only the missing parts of a path and returns its id.

03

Update in place

Write into a folder by name, replacing an existing file without creating duplicates.

04

Progress everywhere

Uploads and downloads report progress straight into a JavaFX ProgressIndicator.

05

Failures with reasons

DriveException tells "Drive full" from "rate limited", with retryable / needs-user flags.

06

Retries that know when to stop

DriveRetry backs off exponentially — and refuses to retry what waiting can’t fix.

07

Android with PKCE

Code verifier, S256 challenge and token exchange, no client secret on the phone.

08

Resumable & cancellable

Android streams uploads with the resumable protocol and can stop mid-transfer.
