Overview

Measure your code. Physically. How many Burj Khalifas tall is your codebase?

Every line counter tells you a number. CodeMeter tells you what the number means. Ten thousand lines of code is a stack of paper nineteen millimetres tall, weighing almost a kilogram — and a big enough codebase is measured in football fields, Eiffel Towers and the trees it would take to print it.

Getting started

Homebrew

brew tap Shashwat-Gupta57/homebrew-tap
brew install codemeter

Winget

winget install ShashwatGupta.CodeMeter

Scoop

scoop bucket add shashwat-gupta57 https://github.com/Shashwat-Gupta57/scoop-bucket
scoop install shashwat-gupta57/codemeter

Nix

nix run github:Shashwat-Gupta57/CodeMeter

JAR

java -jar codemeter.jar

How to use it

  1. InstallHomebrew, Winget, Scoop, Nix or the JAR — see Download.
  2. Scancodemeter scan . in any project.
  3. Explorehistory, compare, milestones and wrapped show how it grows.
  4. Sharecodemeter export -f png -o report.png

Commands

CommandWhat it does
codemeter scan .Scan a project — the story mode
codemeter wrappedYour end-of-year summary
codemeter historyEvery scan, across every project
codemeter compareThis workspace against the last scan
codemeter milestonesProgress towards your next rank
codemeter statsRaw metrics for CI/CD
codemeter export -f png -o report.pngExport to json, pdf, png, svg, csv or md
codemeter configTune the physical assumptions, like paper thickness
codemeter doctorSystem diagnostics
codemeter benchmarkMeasure parsing performance
