Overview

My first game. An endless runner inspired by Chrome Dino and Geometry Dash.

The first game I ever built, right after the terminal stopped being enough. Rex Run borrows the simplicity of Chrome’s offline dinosaur and the rhythm of Geometry Dash — and then adds everything I wished those games had.

Getting started

Requirements: Windows 10 or 11 and Java 21+ (the JRE Installer sets it up in one click).

  1. Install Java onceDownload the JRE Installer, unzip it and click Start Installing JRE — no admin rights. (Skip this if you already have Java 21 or newer.)
  2. Download the appGrab the zip from the Download page.
  3. Unzip anywhere writableDesktop or Documents — the app saves its settings in its own folder.
  4. Run the .exeWindows SmartScreen may warn on first run because the exe isn’t code-signed: More info → Run anyway.

How to use it

  1. Start a runClick “Click to start the game”. Rex starts running on his own; the score climbs with distance.
  2. SurviveJump over stone blocks and pillars with Space. When the floor gets dangerous, Shift flips gravity and Rex runs on the ceiling.
  3. CollectGrab coins for the shop and hearts for extra lives; a shield power-up absorbs a hit.
  4. SpendPress Enter to pause, open the shop and spend your coins.
  5. Make Rex yoursEdit Avatar on the title screen or the pause menu changes how Rex looks.

FAQ & troubleshooting

My coins reset.

Saves.txt sits next to the exe. If the folder is read-only (e.g. inside Program Files), the game can’t save — unzip it to Desktop or Documents.

What does Shift do?

It flips gravity. Rex runs upside-down along the ceiling until you flip it back.

“needs Java 21 or newer”

Install Java once with the JRE Installer (github.com/Shashwat-Gupta57/JRE-Installer), or point JAVA_HOME at a Java 21+ install.

Windows SmartScreen blocked it.

The exe isn’t code-signed. Click More info → Run anyway. The source is public on GitHub if you’d rather build it yourself.

My settings or scores don’t save.

The app writes next to its exe. Unzip it somewhere you can write to, not inside Program Files.

Where does it look for Java?

%LOCALAPPDATA%\OpenJDK Adoptium JRE - SG\JRE first (where the JRE Installer puts it), then %JAVA_HOME%.
