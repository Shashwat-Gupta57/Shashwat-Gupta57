The story

Why Talken REST API

A peer-to-peer messenger still needs a way for two strangers to find each other. Talken’s REST API is the smallest possible answer: a phone book, a key-recovery desk and a post-office box — and nothing else. It never routes a live conversation and never holds a readable message.

Written from scratch in Spring Boot, it ships its own client library that both the desktop and Android apps use, and every request that changes anything is authenticated by a proof derived from the user’s own key.

Highlights

What it does.

01

Discovery

Find a person and their current mesh address — the public user directory.

02

Key recovery

Your private key, sealed on your own device before it ever arrives, recoverable with your password.

03

Offline mailbox

Holds up to 1,000 sealed messages per person for three years and hands them over on sign-in.

04

Groups & channels

Membership, roles and channel metadata, enforced on every change.

05

Own client library

A typed Java client shipped into both apps.

06

Proof, not passwords

Mutations carry an Argon2-derived identity proof, never the key itself.
