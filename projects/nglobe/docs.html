Overview

Your machine’s network traffic, live, on a 3D globe.

Wireshark and Fiddler are incredibly powerful, but they show your traffic as endless rows of text. They have no sense of place. When your laptop quietly talks to a server on another continent, you never feel it.

14,000+lines of code
60fps3D rendering
1command to start

Getting started

From source

git clone https://github.com/Shashwat-Gupta57/NGlobe
cd NGlobe && pip install .
nglobe start

How to use it

  1. InstallClone the repo and pip install .
  2. Startnglobe start — the wizard sets up the certificate, proxy and GeoIP database.
  3. WatchOpen the globe in your browser and use your machine as normal.

FAQ & troubleshooting

Why does it need a certificate?

To show HTTPS requests, mitmproxy must decrypt them locally — only on your own machine.
